# Ohjelmallinen ajattelu — arvioitavat tehtävät AT1–AT3 (julkaisupaketti)

Tämä paketti lisää olemassa olevaan viikkopohjaiseen kurssiin kolme arvioitavaa tehtävää. Kansiot peilaavat kurssin legacy-rakennetta (`viikko-XX/opiskelija`, `viikko-XX/opettaja`), joten tiedostot kopioidaan sellaisenaan vastaaviin kurssikansioihin.

| Tiedosto | Mikä se on | Mihin se kuuluu |
|---|---|---|
| `viikko-02/opiskelija/arvioitava-tehtava-AT1.md` | AT1:n tehtävänanto opiskelijalle (oppitunti 6) | viikon 2 opiskelijakansioon viikkotehtävien rinnalle |
| `viikko-02/opettaja/rubriikki-AT1.md` | AT1:n arviointirubriikki (ES / S- / S / S+) | viikon 2 opettajakansioon |
| `viikko-06/opiskelija/arvioitava-tehtava-AT2.md` | AT2:n tehtävänanto (oppitunti 18) | viikon 6 opiskelijakansioon |
| `viikko-06/opettaja/rubriikki-AT2.md` | AT2:n arviointirubriikki | viikon 6 opettajakansioon |
| `viikko-08/opiskelija/arvioitava-tehtava-AT3.md` | AT3:n tehtävänanto (oppitunnit 23–24) | viikon 8 opiskelijakansioon; viittaa olemassa olevaan `lisamateriaali-l24-esitysrubriikki.md`-tiedostoon samassa kansiossa |
| `viikko-08/opettaja/rubriikki-AT3.md` | AT3:n arviointirubriikki | viikon 8 opettajakansioon |
| `course.at.json` | Osittainen manifesti (vain lesson-06, -18, -24); rubriikkipolut osoittavat tämän paketin kansioihin | kurssin juureen tai yhdistettäväksi kurssin täyteen manifestiin |
| `opettajan-tarkistuslista-AT.md` | Opettajan tarkistuslista: ennen tuntia / tunnilla / arvioinnissa per AT, koontitaulukko ja poikkeamat briefistä | kurssin juureen |

Olemassa olevia viikkotehtäviä (2.1–2.5, 6.1–6.4, 8.1-JS/CS–8.5), dioja, opettajan materiaaleja tai esitysohjetta ei ole muutettu; AT-tiedostot viittaavat niihin tehtävä-id:llä ja suhteellisilla poluilla. Kurssialustalle vienti (itslearning) ei kuulu tähän pakettiin. Kielenhuolto on ajettu (raportti: tuotanto/audit/borje.md).
