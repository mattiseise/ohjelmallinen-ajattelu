# Week 7 — From pseudocode to code

## Week 7 theme

Last week's pseudocode was clear enough for a human; a real computer cannot read it. The course's central question — *"How do I speak to a computer so that it understands what I want it to do?"* — finally gets its real answer in code, in two languages side by side: **JavaScript** in the browser console, and **C#** in an online .NET environment. L19 talks about programming languages and syntax in plain English. L20 and L21 introduce concrete syntax — output, variables, `if/else` — in both languages at once.

## What you will be able to do by the end of the week

- Define *programming language*, *syntax*, *command*, *interpreter / compiler* in plain English.
- Name JavaScript and C# and one typical use of each.
- Open the **browser DevTools console** or **.NET Fiddle** and run a first line of code.
- Declare a variable, print it, do a simple calculation.
- Write a comparison and a first `if/else` block.
- Predict the output of a small program, then run it and check.

## Must-do minimum vs. deepening

**Must-do minimum — every student should leave Week 7 able to:**

- Explain why a programming language is needed when pseudocode is already precise.
- Name JavaScript and C# and one typical use of each.
- In **one** language, run a program that prints a greeting, declares a variable, prints it, and uses one `if/else`.
- Save the code in your notes — AT3 will reuse it.

**Deepening (recommended — AT3 lands next week):**

- Do the same task in the **other** language.
- Translate a Week-6 pseudocode snippet into a program.
- Break the program on purpose; read the error message.

## How the three lessons fit together

L19 explains, without working code, why a programming language has to exist and what *syntax* means. L20 introduces output, values and variables in both languages side by side. L21 adds comparisons and `if/else`, carrying forward the Week-6 **age-limit check**.

## Pick your language

Pick **one** language this week — the one that looks less scary on the first side-by-side slide. You can swap any time. AT3 will ask you to translate a Week-6 snippet into a program in your chosen language; the grade does not depend on the language. JavaScript runs in the browser DevTools console; C# runs in **.NET Fiddle**. No installation needed.
