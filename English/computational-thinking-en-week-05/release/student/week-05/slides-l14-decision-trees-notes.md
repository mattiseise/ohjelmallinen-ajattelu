## Slide 1 — Decision trees — one tree, end to end

Frame this supplement. Lesson 14 introduced the condition; this short deck walks one decision tree slowly so the shape sticks. Tell the class: "By the end of these seven slides you will draw one tree from scratch." Keep the pace easy — this is the deepening lap, not a sprint. Ask the class: "Has anyone drawn a flowchart before? Where?" Often someone has from a math class or a game guide. ~1 min.

## Slide 2 — The everyday rule

Read the umbrella rule aloud. Notice how the English already has the if/else if/else shape baked in, even though we have not drawn anything yet. This matters because rules students already follow have hidden structure — drawing the tree just makes the structure visible. Ask the class: "Which word in the rule signals the first split?" Answer: "if". ~2 min.

## Slide 3 — Draw the tree — branches and tests

Draw it on the board even though it is on the slide. Root at the top, branches downward, leaves at the bottom. Two tests, three leaves. Stress the word *test* — each fork is a question with a yes/no answer the follower can actually check. This is the rule-quality test for the rest of the deck. Ask the class: "Which leaf is reached for sunny weather and a rainy forecast?" Answer: take umbrella. ~3 min.

## Slide 4 — Express the rule as casual if … then …

Same rule, written as bullets. Read them aloud. Point out that the tree and the bullets carry the same information — different views of one rule. Tell the class: this exact shape ("if … else if … else") will appear in pseudocode in Week 6 and in real code in Week 7. They are learning the keyword pattern early. Ask the class: "Which bullet is the leaf 'leave it at home'?" Answer: the else. ~2 min.

## Slide 5 — The IT mirror — should this login attempt be blocked?

Now the IT version. Read the rule slowly — it has three branches just like the umbrella rule. Tell the class: this is the kind of logic that lives behind a real login screen. Banks, school portals, Discord — all of them ran a tree just like this when you logged in this morning. Ask the class: "Where is the safety belt in this rule?" Steer to "4+ tries in 5 minutes." ~2 min.

## Slide 6 — The same tree, different scene

Side by side with slide 3 — same shape, different tests, different leaves. Emphasize: once you can see the shape, you can see it everywhere. The umbrella tree and the login tree are siblings. Ask the class: "Which leaf is reached for a wrong password on the first try?" Answer: ask to retry. Have one student narrate the path top to bottom. ~3 min.

## Slide 7 — Naming the test honestly

End with the rule for good trees: honest tests. A test is honest if the follower can answer it the same way every time without guessing. "Is the user being suspicious?" is not honest — different graders would answer differently. Ask the class: "Rewrite 'is the user being suspicious' as an honest test." Possible answers: failed logins in last 10 minutes, login from a new country. Give them the take-away as homework for Task 5.3. ~3 min.
