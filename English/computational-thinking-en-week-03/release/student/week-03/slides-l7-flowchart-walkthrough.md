# Lesson 7 — Flowchart walkthrough

A shape-by-shape build of one everyday flowchart.

Use only if the class needs the slow build; skip if the live whiteboard sketch lands well.

---

## Slide 1 — Start

```
( Start )
```

Every flowchart begins with exactly one Start oval. It says where the process opens.

For today's example, the process is *"deciding whether to bring an umbrella this morning"*.

---

## Slide 2 — First step

```
( Start )
   |
   v
[ Check the weather forecast ]
```

One rectangle. One action. *"Check the weather forecast"* is one step the follower does.

Notice it does not say *how* the forecast is checked — that detail is hidden inside the box.

---

## Slide 3 — The decision

```
( Start )
   |
   v
[ Check the weather forecast ]
   |
   v
< Is rain probability > 50% ? >
   /                       \
  Yes                       No
```

A diamond holds one yes/no question. Two arrows come out of it — one for each answer. Each arrow has its own short label.

This is the moment a flat list cannot do — the process splits.

---

## Slide 4 — Both branches

```
< Is rain probability > 50% ? >
   /                       \
  Yes                       No
   |                         |
   v                         v
[ Bring umbrella ]      [ Leave umbrella at door ]
```

Each branch carries its own rectangles. The Yes path does one thing; the No path does another. Both branches are honest about what the follower actually does in each case.

---

## Slide 5 — Closing the flowchart

```
( Start )
   |
   v
[ Check the weather forecast ]
   |
   v
< Is rain probability > 50% ? >
   /                       \
  Yes                       No
   |                         |
   v                         v
[ Bring umbrella ]      [ Leave umbrella at door ]
   \                         /
    \                       /
     v                     v
       ( Leave the house )
```

Both paths meet at the End oval. Every path through a flowchart must reach an End oval.

Eight shapes total. One Start, one End, three rectangles, one diamond. The whole umbrella process on one page.

---

## Slide 6 — The same shape, an IT example

Same five shapes; different context.

- Start → *"Read the ticket text"* → *"Can the user log in now?"*
  - Yes → *"Close the ticket"* → End (Closed)
  - No → *"Ask the user for a screenshot"* → End (Wait for reply)

The four flowchart shapes carry an IT process just as cleanly as they carry the umbrella process. Same picture vocabulary; new audience.
