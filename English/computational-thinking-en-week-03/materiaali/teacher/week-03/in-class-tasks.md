# Week 3 — In-class tasks

## Overview

This file contains the **in-class, teacher-led** activities for Week 3. They run during class, not as homework.

- **Activity A — "Whiteboard flowchart relay"** is **🟢 MANDATORY**, slotted in the **55–80 min of Lesson 9**.
- **Activity B — "Audience swap (pair work)"** is **🟣 OPTIONAL**, slotted in the **60–80 min of Lesson 8**.

Both need live classroom interaction — students at the board, pairs comparing audience versions of the same step, the teacher redrawing chunks as named boxes. They cannot be replaced by homework or by an LLM.

---

## Activity A — "Whiteboard flowchart relay" 🟢 MANDATORY

**Goal.** Students see how a tangled high-level flowchart turns into a readable one when reused chunks are pulled out and given verb-phrase names. Going to the board and drawing the named box yourself makes the L9 move physically obvious.

**Group size.** Whole class (one volunteer at the board; the rest observe and contribute).

**Time required.** 25 min (Lesson 9, 55–80 min slot).

### Teacher preparation (before class)

1. **Prepare one vocational process on the board** before students arrive. Suggested scenario: *"A new student arrives — set them up with a school laptop."* Sketch a high-level flowchart of 8–10 boxes left to right. Suggested boxes:
   - *Hand over the laptop and the welcome sheet.*
   - *Open the portal in the browser.*
   - *Enter the student's username.*
   - *Enter the student's password.*
   - *Press Login and wait for the landing page.*
   - *Connect the laptop to the school network.*
   - *Open the school software list.*
   - *Install the standard software set.*
   - *Show the student where the timetable lives.*
   - *Hand the student a printed quick-start card.*
2. **Clear the right-hand side of the board** for redraws. Each named block becomes one new box on the right.
3. Board marker, sticky notes for the closing minute, eraser.

### Step-by-step facilitation

1. **Set the rules (2 min).** *"Find chunks of process that could be named, reusable blocks. Come up, circle the chunk on the left, and write a short verb-phrase name (three words or fewer) on a new box on the right. **What** the box does — not **how**."* More than one valid naming is possible.
2. **Round 1 — first volunteer (5 min).** A student circles a chunk on the left and proposes a verb-phrase name. Likely first catch: *open the portal → enter username → enter password → press Login* becomes *"log the user in"*. Redraw the named box on the right.
3. **Class check (2 min).** *"Without looking at the original chunk, does **log the user in** carry the meaning?"* Hands up. If a strong minority says no, propose a tighter name and settle on one.
4. **Rounds 2–4 — three more volunteers (12 min).** New volunteer each time. Likely catches: *connect to school network → install the standard software set* becomes *"prep the laptop for school"*; *show the timetable / hand the quick-start card* becomes *"hand over for first use"*. Three or four named blocks is a good landing.
5. **Side-by-side compare (2 min).** Left: the original 8–10 box tangle. Right: 4–5 named boxes. Ask:
   - *What did we gain?* (Readability — the larger flowchart fits in one glance.)
   - *What did we lose?* (Detail — the click-by-click steps are no longer on the board.)
   - *Where do the named blocks' details live now?* (A description below each box, a separate flowchart, the IT handbook. Filed, not deleted.)
6. **Sticky-note close (2 min).** Each student writes one verb-phrase on a sticky note — a named block from their own life. Read three aloud and ask whether the name carries the meaning.

### Debrief questions

- Which named block carried the most original detail? Where do those details live now?
- Were there chunks the class first thought were named blocks but turned out unique to this process?
- Which name was hardest to settle on, and why?

### Why it requires the classroom

The relay-at-the-board format, the live redraw, and the collective name-check are the point. Each name has to be defended out loud against *"does it carry the meaning?"*. That cannot survive in homework or in a chat with an LLM.

### Cross-reference

Slot: **55–80 min of Lesson 9** in `teacher-materials.md`. Prepare the 8–10 box flowchart before class.

## Activity B — "Audience swap (pair work)" 🟣 OPTIONAL

**Goal.** Pairs see that the **same single step** opens up into very different lower-level flowcharts depending on the audience. Makes the L8 abstraction lecture physical without a whole-class moment.

**Group size.** Pairs. (Odd numbers: one group of three.)

**Time required.** 20 min (Lesson 8, 60–80 min slot).

### Teacher preparation (before class)

- One shared single-box step that both pairs will open up. Suggested: *"Check the file naming convention."* Write it on the board.
- Two audience prompts on slips, one per pair:
  - **Audience A:** *"a brand-new IT trainee on day one."*
  - **Audience B:** *"a senior IT admin who already knows the convention by heart."*
- Paper and pens for each pair. No slides during the activity.

### Step-by-step facilitation

1. **Explain the rules (2 min).** Both pairs rewrite the same single box, *"Check the file naming convention"*, as a small flowchart of 0–6 sub-steps — *for the audience on their slip*. Independent, no comparing, 8 minutes.
2. **Independent rewrite (8 min).** Pairs work on paper. The teacher does not coach. Pair A is likely to produce 4–6 sub-steps; Pair B 0–2 (or *"already done"*).
3. **Swap and read (4 min).** Pairs swap and write down: (a) how many sub-steps? (b) what level of detail is the other pair's audience? (c) which sub-step would they cut if their own audience were reading it?
4. **Whole-class debrief (4 min).** Two pairs share. Write on the board: *"Same single step. Different audiences. Different right levels of detail. Both are correct flowcharts."* Bridge to L9: *"Tomorrow — when the same chunk reappears, we give it a name."*
5. **Closing reflection (2 min).** Each student writes a one-sentence audience for their Task 3.5 flowchart: *"My lower-level version is for [audience]."* Task 3.5 asks for exactly this sentence.

### Debrief questions

- Was your sub-step count close to your partner pair's, or very different?
- Where did the same word in the original step (*"check"*) end up meaning two different things?
- Which audience felt easier to write for? Why?

### Why it requires the classroom

The simultaneous, visible difference between two pairs writing for two audiences is the point. Without the contrast, the audience-first move stays abstract.

### Cross-reference

Slot: **60–80 min of Lesson 8** in `teacher-materials.md`. Prepare the shared step and the two audience slips before class.
