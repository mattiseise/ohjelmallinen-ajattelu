# Viikko 3 — Opiskelijatehtävät

## Viikon tehtävien yleiskatsaus

Tällä viikolla on **neljä tehtävää**. Vihreällä pisteellä merkitty (🟢 PAKOLLINEN) on **must-do-minimi** — Tehtävä 3.1, jossa piirrät ensimmäisen vuokaaviosi omasta elämästäsi. Kolme violetilla pisteellä merkittyä (🟣 SYVENTÄVÄ) ovat valinnaisia laajennuksia; valitse ne, jotka herättävät kiinnostuksesi.

**AT2 — prosessikuvaus — palautetaan viikon 5 lopussa / viikon 6 aikana.** Tällä viikolla tekemäsi muistiinpanot (vuokaaviot, uudelleenkäytettävät lohkot, abstraktiovalinnat) ovat raaka-ainetta, jota AT2 pyytää. Älä heitä mitään pois.

Tietokone on edelleen **sananmukainen**. Jokaisen vuokaaviolaatikon sisällä olevan vaiheen on oltava niin pieni, että sananmukainen tulkitsija pystyy suorittamaan sen arvaamatta. Kuvan piirtäminen prosessista ei muuta tuota sääntöä.

---

## Tehtävä 3.1 — Piirrä ensimmäinen vuokaaviosi 🟢 PAKOLLINEN

**Tavoite.** Ota yksi tuttu arjen prosessi omasta elämästäsi ja piirrä se pienenä vuokaaviona neljällä muodolla ja vähintään yhdellä päätöskohdalla. Tämä on viikon 3 **must-do-minimi**.

### Vaiheet

1. **Valitse yksi tuttu arjen prosessi**, jonka oikeasti teet ja jossa on vähintään yksi **kyllä/ei-kysymys**. Hyviä valintoja: *"otanko sateenvarjon tänään?"*, *"menenkö bussilla vai kävellen kouluun?"*, *"mikä laturi sopii tähän laitteeseen?"*, *"onko jääkaapissa oleva maito vielä hyvää?"*.
2. **Piirrä vuokaavio paperille** (suositeltavaa) tai tabletille käyttäen neljää muotoa — **soikio** (alku / loppu), **suorakulmio** (yksi vaihe), **vinoneliö** (yksi kyllä/ei-päätös, kaksi lähtevää nuolta), **nuoli** (virtaus).
3. **Pidä se pienenä** — enintään **8 muotoa** yhteensä, Alku ja Loppu mukaan luettuna. Jos tarvitset enemmän, valitse pienempi pala prosessista.
4. **Allekirjoita ja päivää piirros.** Kirjoita **nimikirjaimesi ja tämän päivän päivämäärä** johonkin kohtaan sivua.
5. **Ota valokuva** ja liitä se viikkomuistikirjaasi (tai, jos muistiinpanosi ovat vain tekstiä, piirrä vuokaavio uudelleen pelkkänä ASCII:na).
6. **Vastaa 3–5 lauseella:** Minkä kysymyksen päätösvinoneliösi kysyy? Mitkä ovat sen kaksi polkua? Mikä on **Loppu**-tila kummallakin polulla? (Jokaisen polun on päästävä Loppu-soikioon — ei umpikujanuolia.)

### Esimerkkiranka (ASCII)

```
( Alku ) -> [ Tarkista sääennuste ]
   -> < Onko sadetodennäköisyys > 50 % ? >
        Kyllä -> [ Ota sateenvarjo ]
        Ei    -> [ Jätä sateenvarjo ovelle ]
   -> ( Lähde kotoa )
```

Kuusi muotoa. Sinun voi olla pienempi tai jopa kahdeksan.

> 💡 **Vinkki:** Jos vuokaaviossasi **ei ole vinoneliötä**, olet kirjoittanut listan, jonka ympärille on piirretty laatikot. Etsi yksi kyllä/ei-kysymys, vaikka pienikin.

### Säilytä muistiinpanot

Säilytä päivätty, allekirjoitettu piirros (tai sen valokuva) ja 3–5 lauseen vastauksesi. **AT2 — prosessikuvaus — palautetaan viikon 5 lopussa / viikon 6 aikana**, ja tässä rakentamasi vuokaaviosanasto on juuri sitä, mitä AT2 odottaa.

## Tehtävä 3.3 — Mitä on piilotettu Kirjaudu sisään -painikkeen sisälle? 🟣 SYVENTÄVÄ

**Tavoite.** Valitse yksi painike, jota oikeasti käytät, ja kirjoita ylös, mitä se **piilottaa** sinulta. Harjoittele O8:n liikettä: abstraktion näkemistä.

### Vaiheet

1. **Valitse yksi painike tai valikkokohta** käyttämästäsi ohjelmistosta — koulun portaalin *"Kirjaudu sisään"*, Discordin *"Lähetä"*, Spotifyn *"Toista"*, puhelimesi kameran laukaisin, sähköpostiohjelman *"Vastaa"*.
2. **Listaa vähintään 5 asiaa, jotka piiloutuvat sen painikkeen sisälle** — asioita, jotka tapahtuvat painikkeen painalluksesta etkä näe niitä. *"Kirjaudu sisään"* -painikkeelle: salasanan tarkistus salattua tallennetta vasten, istuntoevästeen saaminen, uudelleenohjaus oikealle aloitussivulle, yrityksen kirjaaminen tietoturvatiimille, sinulle näkyvien valikkokohtien päivittäminen. Järkevät arvaukset käyvät.
3. **Listaa vähintään 2 asiaa, jotka EIVÄT ole piilotettuja** — asioita, jotka painike vaatii edelleen *sinulta*. *"Kirjaudu sisään"* -painikkeelle: *"sinulla pitää jo olla tili"*, *"sinun pitää tietää salasanasi"*, *"sinun pitää olla oikealla kirjautumissivulla, ei kalastelusivulla"*.
4. **Pohdinta (3–5 lausetta).** Kuka on tämän abstraktion yleisö — kuka päätti, mitä piilotetaan, ja miksi? Onko jotakin, minkä *pitäisi* olla näkyvissä mutta jonka se tällä hetkellä piilottaa?

> 💡 **Vinkki:** Kuvittele painike pois ja kuvaa, mitä joutuisit sen sijaan tekemään. Tuo lista on tarkalleen se, mitä abstraktio piilottaa.

### Säilytä muistiinpanot

Säilytä painikkeen nimi, *piilotettu*-lista, *ei piilotettu* -lista ja pohdinta. **AT2 — prosessikuvaus — palautetaan viikon 5 lopussa / viikon 6 aikana**, ja sen nimeäminen, mitä abstraktio piilottaa, on juuri sitä sanastoa, jota AT2 odottaa.

## Tehtävä 3.4 — Tunnista uudelleenkäytetty osa 🟣 SYVENTÄVÄ

**Tavoite.** Etsi prosessin osa, joka esiintyy kahdessa vuokaaviossa, nimeä se lyhyellä verbi-ilmaisulla ja piirrä yksi omista vuokaavioistasi uudelleen niin, että tuo osa on yksi nimetty laatikko. Harjoittele O9:n liikettä: toistuvan kuvion muuttamista nimetyksi, uudelleenkäytettäväksi lohkoksi.

### Esimerkkipari, josta voit aloittaa

Kaksi pientä ammatillista vuokaaviota. Molemmilla on yhteinen prosessin osa — etsi se.

**Vuokaavio A — "Uuden opiskelijan ensimmäinen päivä".**

```
( Alku ) -> [ Luovuta koulun läppäri ]
   -> [ Avaa portaali selaimessa ]
   -> [ Kirjoita käyttäjätunnus ] -> [ Kirjoita salasana ]
   -> [ Paina Kirjaudu sisään ja odota aloitussivua ]
   -> [ Näytä opiskelijalle, missä lukujärjestys on ] -> ( Loppu )
```

**Vuokaavio B — "Help desk -tiketti: arvosanat eivät näy".**

```
( Alku ) -> [ Lue tiketti ]
   -> [ Avaa portaali selaimessa ]
   -> [ Kirjoita help-deskin käyttäjätunnus ] -> [ Kirjoita help-deskin salasana ]
   -> [ Paina Kirjaudu sisään ja odota aloitussivua ]
   -> < Näkyvätkö arvosanat nyt ? >
        Kyllä -> [ Sulje tiketti ]
        Ei    -> [ Pyydä käyttäjältä kuvakaappaus ] -> ( Loppu )
```

### Vaiheet

1. **Etsi yhteinen osa.** Alleviivaa vaiheet, jotka esiintyvät molemmissa vuokaavioissa. Yhteinen osa on *avaa portaali → kirjoita käyttäjätunnus → kirjoita salasana → paina Kirjaudu sisään* — neljä suorakulmiota, kahdesti.
2. **Ehdota lyhyttä verbi-ilmaisua nimeksi** yhteiselle osalle, korkeintaan kolme sanaa. Hyvä: *"kirjaudu portaaliin"*. Huono: *"tee se kirjautumisjuttu"* (ei sisällä merkitystä).
3. **Valitse yksi omista vuokaavioistasi** (Tehtävä 3.1 tai mikä tahansa muistikirjastasi) ja etsi siitä osa, joka saattaisi esiintyä *toisessa* tutussa prosessissa. Ehdota lyhyttä verbi-ilmaisua nimeksi.
4. **Piirrä vuokaaviosi uudelleen** niin, että osan tilalla on yksi nimetty laatikko, joka kantaa verbi-ilmaisua. Laatikon alle kirjoita yksi tai kaksi selkeää lausetta: *"Tämä nimetty lohko tekee: …"*.
5. **Testaa nimi parin kanssa.** Näytä **vain uudelleen piirretty vuokaavio** (nimetty laatikko, ei alkuperäistä yksityiskohtaa) luokkatoverille. Pyydä häntä sanomaan yhdellä lauseella, mitä hän luulee nimetyn laatikon tekevän. Jos hänen arvauksensa vastaa kuvaustasi, nimi on hyvä. Jos ei, nimi kaipaa työtä.

### If you are doing this alone

Jos et löydä luokkatoveria, käytä jotakin näistä:

- **24 tunnin tauko.** Laita uudelleen piirretty vuokaavio sivuun. Lue se nimettyä laatikkoa raikkaasti silmäillen huomenna. *"Pystynkö pelkän nimen perusteella sanomaan, mitä tämä laatikko tekee?"* Jos en, nimeä uudelleen.
- **Luokan chat tai kurssialusta.** Postaa uudelleen piirretty vuokaavio (ilman kuvausta) ja kysy: *"Mitä luulet nimetyn laatikon tekevän?"* Yksi vastaus riittää.
- **Perheenjäsen.** Näytä uudelleen piirros jollekulle, joka ei ole nähnyt alkuperäistä yksityiskohtaa. Kantaako verbi-ilmaisu merkityksen yksinään?

> 💡 **Vinkki:** Hyvä nimi kuvaa, **mitä** lohko tekee, ei **miten** se sen tekee. *"Kirjaudu portaaliin"* on hyvä. *"Avaa selain, kirjoita käyttäjätunnus, kirjoita salasana, paina Kirjaudu sisään"* on osa itse, ei sen nimi.

### Säilytä muistiinpanot

Säilytä esimerkkivuokaaviot, ehdottamasi nimi, uudelleen piirretty vuokaavio nimetyllä laatikolla, yhden lauseen kuvaus ja luokkatoverin reaktio. **AT2 — prosessikuvaus — palautetaan viikon 5 lopussa / viikon 6 aikana**, ja uudelleenkäytettävien lohkojen nimeäminen on juuri sitä sanastoa, jota AT2 odottaa.

## Tehtävä 3.5 — Kirjoita vaihe uudelleen matalammalla tarkkuustasolla 🟣 SYVENTÄVÄ

**Tavoite.** Ota yksi vaihe Tehtävän 3.1 vuokaaviostasi ja avaa se mini-vuokaavioksi, jossa on 3–5 osavaihetta. Kerro, mille **yleisölle** matalamman tason versio on tehty. Harjoittele O8:n liikettä: tarkkuustason tarkoituksenmukaista valintaa.

### Vaiheet

1. **Valitse yksi vaihe Tehtävän 3.1 vuokaaviostasi**, joka piilottaa sekvenssin — esim. *"Tarkista sääennuste"*, *"Valitse oikea laturi"*.
2. **Kirjoita tuo vaihe uudelleen mini-vuokaaviona, jossa on 3–5 osavaihetta.** Saatat tai et tarvitse uutta vinoneliötä. Esimerkiksi *"Tarkista sääennuste"* muuttuu:

   ```
   ( Alku ) -> [ Avaa sääsovellus ]
      -> [ Etsi tämän päivän ennuste ]
      -> < Sadetodennäköisyys > 50 % ? >
            Kyllä / Ei
      -> ( Takaisin päävuokaavioon )
   ```

3. **Kerro yleisö yhdellä lauseella.** *"Tämä matalamman tason versio on [yleisö]-yleisölle."* Ole täsmällinen: *nuorempi sisarus, joka ei ole ikinä käyttänyt sääsovellusta*, *aivan uusi help-desk-agentti ensimmäisenä päivänä*, *minä itse puolen vuoden kuluttua*.
4. **Valinnainen sparrauskumppanivaihe.** Liitä **molemmat versiot** LLM:ään seuraavalla kehotteella. **Päätä hyväksy / muokkaa / hylkää** jokaiselle ehdotukselle ja perustele yhdellä lyhyellä lauseella, *miksi*.

```
You are my sparring partner, not my teacher. I am a vocational
ICT student practising abstraction. Below is one step from my
flowchart at two levels of detail, plus the audience I picked.

High-level step: [paste]
Lower-level mini-flowchart: [paste]
Audience: [paste your audience sentence]

Please challenge me. For the audience I named:
- Has the meaning drifted between the two versions?
- Is the level of detail right for this audience?
- Is there a sub-step that itself still needs to be opened up?

Do not give me the "right" answer. Ask me a question that helps
me see the gap myself.
```

**Älä liitä LLM:n tekstiä lopulliseen vuokaavioosi.** LLM on sparrauskumppani; vuokaavio on sinun.

5. **Pohdinta (3–5 lausetta).** Millainen haaste oli hyödyllisin — merkityksen ajautuminen, väärä tarkkuustaso vai liian iso osavaihe? Mitä pidit, mitä hylkäsit?

> 💡 **Vinkki:** Jos hyväksyt yli 80 % LLM:n ehdotuksista, et haasta riittävän kovasti takaisin. *"Olisinko muuttanut tätä, jos luokkatoveri olisi kysynyt?"* Jos en, hylkää.

### Säilytä muistiinpanot

Säilytä molemmat versiot, yleisölause, LLM-keskustelu (jos ajoit sen) päätöksinesi ja pohdinta. **AT2 — prosessikuvaus — palautetaan viikon 5 lopussa / viikon 6 aikana**, ja tässä rakentamasi sanasto on sitä, mitä AT2 odottaa.
